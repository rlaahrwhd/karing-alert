# 카링 알림이

## 소스로 실행하기

Windows와 Python 3.10~3.12가 필요합니다. 이 폴더에서 다음 명령을 실행하세요.

    python -m pip install -r requirements.txt
    python app.py

테스트: python -m unittest discover -s tests -v

실행용 ZIP은 GitHub Releases에 별도로 올려주세요.


Windows 화면에서 게이지 전체 영역을 한 번 지정하면 숫자 세 개를 자동으로 구분해 읽습니다. 사용자가 설정한 상한 이상 / 하한 이하일 때 화면과 음성으로 알려주는 시제품입니다. 기본값은 **800 이상 / 100 이하**입니다.

## v7 안내 문구 변경

화면과 음성의 실 안내를 빨간실 맞아줘요 / 초록실 맞아줘요 / 노란실 맞아줘요로 변경했습니다. 남성 InJoon 음성과 기본 대비 +30% 속도를 유지합니다.

## 남성 음성 · 속도 +30%

- 한국어 남성 **Microsoft InJoon Neural** 음성으로 교체했습니다. 속도는 기본보다 30% 빠르게 설정했습니다.
- 빨간·초록·노란 실, 한계값, 복수 게이지 위험 안내의 음성 파일 5개를 포함합니다. 게임 중 인터넷 연결이나 별도 음성 설치가 필요하지 않습니다.
- 음량 슬라이더와 음성 테스트 모두 같은 남성 안내음을 사용합니다. 0%는 음소거입니다.
- 음성을 재생하지 못하면 오류를 표시하며 다른 목소리로 자동 변경하지 않습니다.

## v4 변경 사항

- 실행 파일은 **카링 알림이.exe**이며, 제공한 카링 이미지가 실행 파일과 창 아이콘에 적용됩니다.
- 메이플스토리 폰트를 유지하면서 DPI 인식과 정수 픽셀 크기를 적용하고, 작은 글씨의 기본 크기를 높였습니다. 실제 화면에서의 선명도 개선 정도는 확인이 필요합니다.

- **글자 크기**에서 80~130%를 선택하면 본문·숫자·버튼·안내 글자의 크기가 즉시 바뀝니다. 선택한 크기는 저장됩니다.
- 음성 알림과 항상 위에 표시를 둥근 **켜짐 / 꺼짐 토글**로 변경했습니다. 클릭하거나 Tab으로 이동 후 Space/Enter로 전환할 수 있습니다.
- 버튼을 **모니터링 시작 / 모니터링 종료**로 변경했습니다. 종료를 눌러도 프로그램 창은 유지됩니다.
- 페이즈 선택에 **1**을 추가했습니다. 1페이즈는 실 색상만 안내합니다. 예: “혼돈 게이지가 너무 높아요! 빨간실 맞아줘요.” 모든 페이즈에서 위치 안내를 생략하고 음성은 “빨간실 맞아줘요”처럼 실 색상만 말합니다.

## 기존 기능

### 전체 영역 지정 · 음량 · 메이플스토리 폰트

사용자가 제공한 메이플스토리 TTF 폰트를 프로그램에 포함했습니다. 본문은 Light, 제목·주요 버튼·게이지 숫자는 Bold를 사용합니다. 폰트는 프로그램 실행 중에만 불러오므로 Windows에 별도 설치할 필요가 없습니다. 소스로 실행할 때도 `fonts` 폴더를 함께 보관하세요.

- 영역은 전체 게이지를 한 번만 지정합니다. 위쪽 숫자=혼돈(보라), 왼쪽=도올(초록), 오른쪽=궁기(노랑)로 구분합니다.
- 숫자 세 개와 배치가 확인될 때만 안내합니다. 주변의 다른 숫자가 들어오지 않도록 게이지에 맞춰 선택하세요. 아래 흉수 그림은 포함되어도 됩니다.
- **음성 음량** 슬라이더는 0~100%이며 기본값은 80%입니다. 0%는 음소거입니다. 변경은 다음 음성 안내부터 반영되고, 테스트 음성에도 같은 음량을 사용합니다. Windows 전체 음량은 바꾸지 않습니다.
- 이전 버전에서 지정했던 개별 숫자 영역은 새 방식으로 한 번 다시 지정해주세요. 이전 테마와 상한·하한 설정은 유지할 수 있습니다.

- 오른쪽 위 **라이트 / 다크** 버튼으로 모드를 즉시 바꿀 수 있습니다. 선택한 모드는 자동 저장됩니다.
- 게이지별 카드와 색상 막대, 밝은 청록색 포인트를 적용했습니다. 작은 화면에서는 세로로 스크롤할 수 있습니다.
- v3부터 본문과 숫자 모두 첨부된 메이플스토리 폰트를 사용합니다.
- **알림 조건**에서 상한과 하한을 입력한 다음 **설정 적용** 또는 Enter를 누릅니다. 세 게이지에 공통 적용되며 감시 중에도 변경할 수 있습니다.
- 0~1000의 정수만 허용하고 하한은 상한보다 작아야 합니다. 적용한 값은 다시 실행해도 유지됩니다. 모니터링 시작 시에도 입력한 값을 검사하고 적용합니다.

## 사용 방법

1. 압축을 모두 풀고 **카링 알림이.exe**를 더블클릭합니다. `_internal` 폴더를 실행 파일 옆에 함께 보관하세요. 소스로 실행하려면 Python 3.10~3.12에서 `pip install -r requirements.txt` 후 `python app.py`를 실행합니다.
2. 메이플스토리를 창모드 또는 테두리 없는 창모드로 열고 게이지를 보이게 합니다.
3. **게이지 전체 영역 지정**을 누르고 세 숫자를 모두 포함하는 게이지 전체를 드래그합니다. 숫자 1000도 잘리지 않도록 조금 여유를 둡니다. 주변의 다른 숫자는 제외해주세요.
4. 페이즈 1·2·3 중 하나을 선택하고 음량 슬라이더를 조절한 뒤 **음성 테스트**로 소리를 확인합니다. 남성 음성 파일이 포함되어 별도 음성 설치가 필요하지 않습니다.
5. **모니터링 시작**을 누릅니다. 옆의 작은 이미지가 실제 캡처한 영역입니다. 표시 값이 게임의 숫자와 일치하는지 확인합니다.
6. 전투가 끝나거나 화면을 이동하기 전 **모니터링 종료**를 누릅니다. 게임 위치·해상도·UI 배율을 변경했다면 영역을 다시 지정합니다.

알리미 창이 게이지를 가리지 않도록 옮겨두세요. 설정은 프로그램 옆 `settings.json`에 저장됩니다. 화면 이미지는 파일로 저장하거나 외부로 전송하지 않습니다.

## 안내 규칙

| 게이지 | 설정한 상한 이상일 때 | 설정한 하한 이하일 때 |
|---|---|---|
| 혼돈 | 빨간 실 | 노란 실 |
| 도올 | 노란 실 | 초록 실 |
| 궁기 | 초록 실 | 빨간 실 |

위치는 제공된 참고 이미지 기준입니다. 2페 왼쪽/중앙/오른쪽 = 빨강/초록/노랑, 3페 = 빨강/노랑/초록입니다. 페이즈 전환은 직접 선택합니다.

- 약 0.5초 간격으로 인식합니다. PC 성능에 따라 길어질 수 있습니다.
- 신뢰도 85% 이상 숫자가 3회 연속 읽혀야 안내하며, 세 값 중 하나라도 확인되지 않으면 실 안내를 보류합니다. 인식 변화 폭이 120을 넘으면 다시 확인합니다. 빠른 실제 변화도 잠시 늦게 반영될 수 있습니다.
- 같은 상황이 계속되면 음성은 최소 10초 간격으로 반복합니다. 음성 알림을 끄면 화면 표시는 유지됩니다.
- 한 실은 두 게이지에 영향을 줍니다. 다른 게이지가 이미 위험한 방향이라면 실을 바로 맞으라는 안내 대신 함께 확인하라고 경고합니다. 패턴별 변화량과 미래 수치는 예측하지 않습니다.
- 0 또는 1000은 한계값 경고를 내며 일반 실 조절 안내를 하지 않습니다.
- OCR은 화면 효과나 숫자 글꼴에 따라 오인식할 수 있습니다. 실전 자동 검증은 아직 되지 않았으므로 실제 숫자를 함께 확인하며 연습 모드에서 먼저 조정하세요.

게임 입력은 사용자가 직접 수행하며, 이 프로그램은 화면 캡처와 알림 기능만 제공합니다.

## 검증과 출처

`python -m unittest discover -s tests -v`로 경계값, 증감 관계, 인식 실패 및 알림 간격을 검사할 수 있습니다.

v4에서는 1페이즈 색상 안내와 글자 크기·페이즈 저장을 포함한 테스트 14개를 통과했습니다. 새 참고 이미지 전체에서 숫자 3개를 모두 500으로 인식하는 것도 확인했습니다. 자동 실행 환경의 Tcl 제한으로 실제 창의 시각 검증은 하지 못했으며, 실제 게임 화면 캡처부터 음성 출력까지의 통합 동작도 아직 검증하지 못했습니다.

- [RapidOCR](https://github.com/RapidAI/RapidOCR)
- [MSS 화면 캡처 문서](https://python-mss.readthedocs.io/stable/)
- 실/게이지 증감 및 페이즈 위치: 사용자가 제공한 이미지

새 폴더에서 이전 설정을 사용하려면 이전 프로그램 옆 settings.json을 새 카링 알림이.exe 옆으로 복사하세요.

음성 제작: Microsoft Edge 온라인 음성 서비스, ko-KR-InJoonNeural. 제작 도구: https://github.com/rany2/edge-tts (프로그램 실행 시에는 사용하지 않음).

v5 검증: 테스트 16개 통과, 안내음 5개 무음 재생 검사 통과, 음량 0/50/100%의 신호 크기 검증 완료. 청감 품질과 실제 게임 중 출력은 직접 확인이 필요합니다.
