# 카링 알림이

선택한 모니터의 카링 게이지를 읽고 “빨간실 맞아요 / 초록실 맞아요 / 노란실 맞아요”로 안내하는 Windows 프로그램입니다.

## v12 변경 사항

- 림보 안내 문구와 남성 음성을 **충전 완료**로 변경했습니다. 음성 속도는 +30%입니다.
- 구슬 내부뿐 아니라 위쪽 가장자리의 왼쪽·중앙·오른쪽이 모두 밝게 찬 상태를 확인합니다.
- 완충을 5회 연속 확인해야 안내합니다. 기존보다 보수적으로 판정하므로 효과에 가려지면 알림이 늦어질 수 있습니다.

## v11 변경 사항

- **카링 게이지 / 림보 정화 게이지** 탭을 추가했습니다. 탭마다 화면 영역을 따로 저장합니다.
- 림보 탭에서 **림보 게이지 영역 지정**을 눌러 게임 모니터를 선택하고, 반원 테두리와 중앙 구슬을 포함한 게이지 전체를 드래그한 뒤 **모니터링 시작**을 누르세요.
- 제공된 완충 이미지처럼 중앙 구슬이 밝은 청록색으로 빛나는 상태를 5회 연속 확인하면 **“충전 완료”**라고 안내합니다. 숫자 백분율을 읽는 기능은 아닙니다.
- 음량·음성 간격·음성 켜기 설정은 두 탭에 공통 적용됩니다. 완충이 유지되면 설정한 간격으로 반복 안내합니다.
- 탭을 바꾸면 모니터링이 종료됩니다. 선택한 탭에서 다시 시작하세요.

## v10 변경 사항

실 안내 문구와 남성 음성을 XX실 맞아요로 변경했습니다. 음성 속도는 +30%입니다.

## v9 변경 사항

- 음성 간격을 **1~300초**로 설정할 수 있습니다. 기본값은 10초입니다.
- 간격을 입력한 뒤 **설정 적용** 또는 Enter를 누르면 모니터링 중에도 반영되고 저장됩니다.
- 간격은 음성 시작 사이의 최소 시간입니다. 현재 음성이 재생 중이면 종료될 때까지 기다려 겹쳐 재생하지 않습니다.
- 페이즈 선택 기능과 관련 저장 항목을 제거했습니다. 이전 설정 파일은 그대로 읽을 수 있습니다.

## 실행 및 사용

1. 실행용 ZIP을 모두 풀고 **카링 알림이.exe**를 실행합니다. `_internal` 폴더를 함께 보관하세요.
2. 메이플스토리를 창모드 또는 테두리 없는 창모드로 엽니다.
3. **게이지 전체 영역 지정**을 누르고 게임이 있는 모니터를 선택합니다.
4. 선택한 화면의 미리보기에서 세 숫자가 포함된 게이지 전체를 드래그합니다. 주변의 다른 숫자는 제외하고, 1000이 표시될 여백까지 확보하세요.
5. 상한·하한과 음성 간격을 입력하고 **설정 적용**을 누릅니다. 기본 기준은 800 이상 / 100 이하입니다.
6. 음량을 조절하고 **음성 테스트**로 확인한 뒤 **모니터링 시작**을 누릅니다.
7. 전투가 끝나거나 화면 위치를 바꿀 때는 **모니터링 종료**를 누릅니다. 창은 유지됩니다.

게임 창 위치, 화면 배율, 모니터 배치·해상도를 변경하면 영역을 다시 지정하세요. 알리미로 게이지를 가리지 마세요.

## 설정

- 다크·라이트 모드, 글자 크기 80~130%, 음량 0~100%를 지원합니다.
- 음량 0%는 음소거입니다. 한국어 남성 InJoon 음성은 기본 대비 30% 빠릅니다. 파일이 포함되어 인터넷이나 별도 음성 설치가 필요하지 않습니다.
- 메이플스토리 Light/Bold 폰트가 포함됩니다. Windows에 설치하지 않습니다.
- 항상 위에 표시의 기본값은 꺼짐입니다. v8 이전의 기본 켜짐 설정은 첫 실행에서 꺼짐으로 전환하고, 이후 직접 선택한 상태를 유지합니다.
- 설정은 실행 파일 옆 `settings.json`에 저장됩니다. 업데이트 시 이 파일을 새 실행 파일 옆으로 복사하면 설정을 이어 쓸 수 있습니다.

## 게이지와 안내

위쪽 숫자=혼돈(보라), 왼쪽=도올(초록), 오른쪽=궁기(노랑)로 구분합니다.

| 게이지 | 상한 이상 | 하한 이하 |
|---|---|---|
| 혼돈 | 빨간실 맞아요 | 노란실 맞아요 |
| 도올 | 노란실 맞아요 | 초록실 맞아요 |
| 궁기 | 초록실 맞아요 | 빨간실 맞아요 |

신뢰도 85% 이상 숫자 세 개가 3회 연속 확인될 때만 안내합니다. 큰 인식 변화는 재확인하며, 화면 효과에 따라 오인식하거나 안내가 늦어질 수 있습니다. 다른 게이지도 위험해질 수 있는 상황과 0/1000 한계값에서는 확인 경고를 냅니다.

화면 이미지는 저장하거나 외부로 전송하지 않습니다. 게임 입력은 사용자가 직접 수행합니다.

## 소스로 실행

Windows, Python 3.10~3.12에서 소스 폴더를 열고 실행합니다. `assets`와 `fonts` 폴더가 필요합니다.

    python -m pip install -r requirements.txt
    python app.py

테스트:

    python -m unittest discover -s tests -v

v12 테스트 25개 통과. 가장자리 일부가 덜 찬 합성 이미지와 짧은 발광에 대한 회귀 테스트를 포함합니다. 림보는 제공된 두 이미지와 크기·밝기 변형에서 확인했습니다. 실제 듀얼 모니터 UI 조작과 게임 중 통합 동작은 자동 실행 환경에서 검증하지 못했습니다. 전투 효과나 게이지 외형 변화에 따라 인식이 달라질 수 있습니다.
